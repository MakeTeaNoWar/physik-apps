## Aufbau

Jede App hat einen eigenen Ordner:

- `index.html` – aktuelle Version (das ist die Live-Seite)
- `versionen/JJJJ-MM-TT_NN_<name>.html` – alle Fassungen mit Datum
- `qr_<name>.png` – QR-Code für die Klasse
- `README.md` – Beschreibung

Alle Seiten sind für Suchmaschinen gesperrt (noindex). Es liegen keine Pläne, Klassenlisten oder sonstigen personenbezogenen Daten im Repo.
