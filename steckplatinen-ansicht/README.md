# Steckplatinen-Ansicht

NWT Fahrrad-Trittleistungsmessung: komplette Messkette (Arduino, HX711, DMS-Brücke, LCD) als Steckbrett-Ansicht.

- **Live:** https://schulapplikationen.github.io/physik-apps/steckplatinen-ansicht/
- **QR-Code für die Klasse:** `qr_steckplatinen-ansicht.png`
- **Aktuelle Version:** `index.html` (Stand 2026-09-09)
- **Versionen:** Ordner `versionen/` – jede Fassung als `JJJJ-MM-TT_NN_steckplatinen-ansicht.html`, die neueste ist identisch mit `index.html`.

Gehört zu signalkette-wheatstone (gleiche Schaltung als Schaltplan).
